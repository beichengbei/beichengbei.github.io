## 加一篇新作品

1. 在 `作品/` 下新建 `年份-标题.md`
2. 照着已有文件填 frontmatter（字段定义见 `src/content.config.ts` 的 schema）
3. 写正文，`draft: false`
4. `npm run build` 通过后 `git push`

## 开发

```bash
npm run dev      # localhost:4321，草稿可见
npm run build    # 构建 + 校验 frontmatter
```

Astro 7 + Tailwind 4，静态输出，GitHub Actions 部署到 Pages。
