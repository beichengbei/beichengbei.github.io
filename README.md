## 加一篇新作品

1. 在 `作品/` 下新建 `年份-标题.md`
2. 照着已有文件填 frontmatter（字段说明见 `CLAUDE.md`）
3. 写正文，`draft: false`
4. `npm run build` 确认通过 → `git push` → 网站自动更新

## 开发

```bash
npm run dev      # localhost:4321，草稿可见
npm run build    # 构建 + 校验 frontmatter
```

技术栈：Astro 7 + Tailwind 4，静态输出，GitHub Actions 部署到 Pages。
